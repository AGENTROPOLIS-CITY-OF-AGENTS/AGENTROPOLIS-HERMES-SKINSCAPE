# 21st.dev Vault

Purpose: capture high-value interaction patterns from 21st.dev / Hyperiux-style component references, then adapt them into AGENTROPOLIS-native design primitives.

## Rules
- Reference patterns, do not create runtime dependencies on the source site.
- Replace benchmark copy, imagery, and branding with AGENTROPOLIS assets.
- Bind every accepted component to AGENTROPOLIS tokens.
- Preserve accessibility and reduced-motion behavior.
- Prefer macro spatial storytelling at World, Region, District, Building, and Office layers.
- Do not use cinematic motion as a substitute for Surface Tool precision UI.
- External media URLs are not canonical assets. Production builds should use owned/R2-hosted media.
